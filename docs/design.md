# Dizayn parametrlari

## Ochilish
| | |
|---|---|
| Trigger | y = 0, ekran markazidan ±150 px |
| Kutish | 150 ms |
| Davomiyligi | 500 ms |
| Easing | spring `cubic-bezier(.3, 1.35, .45, 1)` |
| Kontent | +160 ms kechikib paydo bo'ladi |
| Scroll | tab almashadi, 250 ms throttle |

|---|---|

| Davomiyligi | 260 ms |
| Easing | ease-in `cubic-bezier(.4, 0, .7, .2)` |
